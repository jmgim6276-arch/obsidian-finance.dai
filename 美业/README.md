## 美业财税要点（2025–2026 阶段汇总）

### 1. 化妆品消费税
- **税目**：高档化妆品消费税税率 15%（含进口环节）
- **不征税情形**：生产环节销售给批发零售环节、出口
- **关键政策依据**：财政部 2016 年消费税调整后未变动

### 2. 医美服务税收待遇
- **增值税**：医疗美容服务按现代服务业 6% 计税；属医疗机构（具备《医疗机构执业许可证》且为非营利性）从事的医疗服务可免征增值税
- **企业所得税**：营利性医美机构按 25% 标准税率，符合小型微利条件可享受优惠
- **个人所得税**：医美机构按"经营所得"或"工资薪金"代扣

### 3. 生活美容（美容美发美甲）
- **增值税**：属生活服务业 6%，小规模纳税人月销售额 10 万以下季度 30 万以下免征
- **行业税负痛点**：上游进货发票获取难，进项不足
- **代账行业建议**：建议核定征收 / 简易计税

### 4. 行业监管要点
- 医美需取得《医疗机构执业许可证》、医师资质
- 化妆品需备案（普通）/ 注册（特殊）
- 跨境进口美容仪器、化妆品需 CCC 认证或 NMPA 备案
